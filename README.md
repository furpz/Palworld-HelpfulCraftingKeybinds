## Description

Adds helpful keybinds while in any crafting menu (workbench, furnace, etc.) so you don't have to move your mouse around to select quantity or start crafting.

## Main Features & Keybinds

### Fractional Splitting
Pressing <kbd>1</kbd>–<kbd>9</kbd> fractionally splits the crafting quantity:
* <kbd>1</kbd> selects the maximum quantity.
* <kbd>2</kbd> selects half (1/2) of the maximum quantity.
* <kbd>3</kbd> selects 1/3, <kbd>4</kbd> selects 1/4, and so on.

### Memory Recall
Pressing <kbd>\`</kbd> / <kbd>~</kbd> recalls and reapplies the last numeric quantity selected via <kbd>1</kbd>–<kbd>9</kbd>. For example, if you can craft up to 100 arrows and press <kbd>2</kbd>, the slider moves to 50. Pressing <kbd>\`</kbd> later will re-select 50 arrows, keeping batch sizes consistent.

### Increment Keys
* <kbd>A</kbd> / <kbd>D</kbd>: Decrement / increment crafting quantity by 1.
* <kbd>Shift</kbd> + <kbd>A</kbd> / <kbd>D</kbd>: Decrement / increment crafting quantity by 10.

*Note: Key assignments and increment step values can be adjusted in the configuration file.*

### Easy Confirmation
* Holding <kbd>Shift</kbd> while pressing any fractional split key immediately starts the craft (e.g., <kbd>Shift</kbd> + <kbd>1</kbd>).
* Pressing <kbd>Space</kbd> immediately starts the craft.
